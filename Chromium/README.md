# Chromium в myBro

Проверка движка использует подписанную сборку ungoogled-chromium 157.0.8103.78-1.1 для macOS arm64. Она находится в `.build/Chromium.app`. У этой предварительной сборки системное имя Chromium и отдельный каталог профилей `.build/mybro-chromium-profile`. При запуске включается переключение на вкладки выбранной группы. Вкладки остаются сверху, вертикальная лента групп отключена. Верхние переключатели групп со счётчиками по образцу Яндекс Браузера пока есть только в прототипе SwiftUI.

```sh
cd $GRAYFOX_ROOT
rtk proxy sh Chromium/run-preview.sh
```

В подписанной предварительной сборке нажмите правой кнопкой на название группы и выберите команду фокусировки на группе (в английском интерфейсе — **Focus on Tab Group**). Обычный клик по цветной метке управляет сворачиванием. В режиме фокуса `+` и `⌘T` открывают вкладку в активной группе. Если команда фокусировки отсутствует, выйдите из предварительной сборки и запустите её указанным скриптом, чтобы применились флаги.

Патч для сборки из исходников добавляет слева на горизонтальной полосе счётчик вкладок окна и кнопки групп со счётчиками. Клик по группе показывает её вкладки и возвращает к последней выбранной в ней вкладке в текущем окне. Счётчик окна переключает на вкладки вне групп. Дополнительные группы доступны через стрелку.

Установка распакованных расширений доступна в `chrome://extensions/` через «Режим разработчика» → «Загрузить распакованное расширение». В `.build/ublock/uBlock0.chromium` находится официальный распакованный uBlock Origin 1.76.4 (MV2). Профили открываются через кнопку профиля, менеджер паролей — через `chrome://password-manager/passwords`.

## Проверка

```sh
rtk proxy env MYBRO_PLAYWRIGHT=/path/to/playwright/node_modules/playwright \
  node Tests/chromium-smoke.cjs .build/Chromium.app/Contents/MacOS/Chromium \
  .build/ublock/uBlock0.chromium
```

Проверка прошла на подписанном Chromium. Тестовый MV2 отменил сетевой запрос, а MV3 выполнил скрипт на странице. Сохранённый логин пережил перезапуск и отсутствовал в другом профиле. Тест использует тестовый Keychain Playwright. uBlock Origin 1.76.4 отдельно отменил запрос к рекламному ресурсу по штатным спискам. Имя рекламного хоста в тесте направляется на локальный HTTP-сервер.

## Исходники

`sh Chromium/prepare.sh` проверяет закреплённый тег macOS и подключает патчи для переключателя групп, Chromium focus mode и имени myBro в метаданных macOS. `sh Chromium/build-native.sh` собирает и проверяет локальную подпись приложения. Скрипт использует зависимости из `.build/toolchain` или из системного PATH. Для компиляции нужен Metal Toolchain для Xcode. Готовый путь выводится после проверки подписи. Его можно передать в `MYBRO_CHROMIUM_APP` при запуске `Chromium/run-preview.sh`. Нативный тест нового сценария — `MyBroTabGroupTest.NewTabStaysInSelectedGroup` в цели Chromium `browser_tests`.
