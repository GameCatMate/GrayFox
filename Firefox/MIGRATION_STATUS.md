# Состояние переноса — 19.11.2026

Полный перенесённый профиль выбран по умолчанию:

`~/Library/Application Support/myBro Firefox/Profiles/<profile>`

Обычный запуск приложения без `-profile` проверен: процесс открыл `places.sqlite` именно из полного перенесённого профиля.

В штатном менеджере профилей его имя — **myBro Firefox**. Первая частичная копия оставлена в `Profiles/Default`, переименована в менеджере в «Неполный перенос — резервная копия» и не выбрана по умолчанию. Это отдельные данные новой реализации, не прежний WebKit-профиль.

Сверено:

- 215 вкладок, 4 группы; после перезапуска 213 вкладок остаются отложенными.
- 111 закладок с деревом папок.
- 2 записи загрузок.
- Все 48266 исходных строк истории найдены: 47832 в Places, 434 в `mybro-history-overflow.json`. Сверка каждого ключа посещения/ID: **0 отсутствующих нативных, 0 отсутствующих дополнительных**. Новая навигация может добавлять свои посещения после переноса.
- Сохранены старые приложение, Swift-исходники, UserDefaults и Keychain. SHA-256 прежнего бинарника не изменился.

## Ожидается только перенос текущих паролей

macOS Security вернул `-25320: In dark wake, no UI possible`. Пароли не были прочитаны, не попали в чат/терминал и не записывались во временный CSV/JSON. Старое парольное хранилище остаётся нетронутым. Найденный ранее CSV на рабочем столе не подменял более свежие пароли из текущего Keychain.

После пробуждения и разблокировки Mac:

```sh
rtk proxy python3 Firefox/migrate.py   --profile "~/Library/Application Support/myBro Firefox/Profiles/<profile>"   --passwords-only
```

Это добавляет только доступные пароли; полный перенос истории и вкладок повторять не надо. Пароли проходят через pipe в нативный Firefox Login Manager. При совпадении сайта/логина уже существующая запись Firefox сохраняется.

## Что не переносилось

Cookies и действующие входы WebKit, содержимое веб-хранилищ и расширения Chromium не копировались. Firefox-версии расширений устанавливаются отдельно. Менеджер паролей/автозаполнение новой версии проверены на синтетической HTTPS-форме; подписанный uBlock Origin 1.76.4 проверен в одноразовом профиле.
