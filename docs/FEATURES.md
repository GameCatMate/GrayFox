# myBro: функции и ограничения

Новая Gecko-версия, её функции и реальные проверки: [Firefox/README.md](../Firefox/README.md). Таблицы ниже описывают сохранённую WebKit-версию.

Сверено с исходниками 19.11.2026. «Есть» означает реализацию в коде; дополнительные ограничения указаны в строке. Реальные сайты и весь тестовый набор при подготовке документа не запускались.

## Импорт и экспорт

| Данные | Vivaldi / Яндекс → myBro | Архив myBro → myBro |
| --- | --- | --- |
| Закладки и папки | `Bookmarks` JSON, с деревом папок | Да |
| История посещений | SQLite `History`, чтение без записи в исходный профиль | Да |
| Открытые вкладки | Поддерживаемая сохранённая SNSS-сессия либо JSON расширения TabExport | Да |
| Стандартные группы / цвета | Из поддерживаемой сессии либо доступного tabGroups API | Да |
| Рабочие пространства Vivaldi | Из поддерживаемой сессии и Preferences; не универсальная поддержка любых форматов | Как группы myBro |
| Закрепление вкладок | Да | Да |
| Пароли | Через CSV штатного экспорта; не расшифровка исходного Login Data | Да, внутри зашифрованного архива |
| История загрузок | Метаданные; пути к файлам не привязываются автоматически | Метаданные; сами файлы не переносятся |
| Настройки | Полный перенос произвольных настроек исходного браузера отсутствует | Только allowlist; см. SETTINGS |
| Cookies / активные авторизации | Нет | Нет |
| LocalStorage / IndexedDB / cache / Service Workers | Нет | Нет |
| Расширения и их данные | Нет | Нет |
| Сертификаты / синхронизация / карты | Нет | Нет |
| Геометрия и число исходных окон | Вкладки объединяются в модель myBro; точное воспроизведение окон не реализовано | Нет полного многоконного профиля |

TabExport исключает инкогнито и неподдерживаемые URL. Зашифрованные сессии Яндекса не читаются этим парсером. Файл живых вкладок имеет приоритет над сессией из папки. При merge повторы вкладок с одинаковыми группой, URL, внутренней страницей, localFile и pinned могут объединяться; «абсолютно всё один к одному» не гарантируется.

## Отдельный Chromium

В скриптах закреплён ungoogled-chromium **157.0.8103.78-1.1**. Это закрепление проекта, а не утверждение о последнем доступном релизе.

- Запуск: `rtk proxy sh Chromium/run-preview.sh`.
- Расширения: `chrome://extensions/`; штатные Chromium-профили и менеджер паролей.
- Ранее проверялись тестовый MV2 blocking webRequest, MV3 content script, uBlock Origin 1.76.4 и изоляция профилей.
- Изменения переключателя групп оформлены как исходные `.patch`. Наличие патча не означает его присутствия в запускаемой по умолчанию готовой `.build/Chromium.app`.
- Скрипт сборки требует toolchain и Metal; полный rebuild Chromium при подготовке карты не выполнялся.
- Этот Chromium не получает автоматически сохранённые данные основного WebKit-приложения.

## Ограничения и нерешённые вопросы

1. Основная оболочка и Chromium ещё не объединены; исходное требование расширений внутри нашего интерфейса выполнено лишь отдельной проверочной сборкой.
2. Нет полноценного побайтового импорта профиля и активных авторизаций. Сохранённый пароль и действующая сессия входа — разные данные.
3. Нет фоновой выгрузки вкладок по памяти, встроенной синхронизации, полноценного режима чтения и движковых функций Chromium в WebKit.
4. Переход на отдельный myBro Firefox выполнен в новой папке `Firefox/`, WebKit-версия сохранена. Совместимость каждого Google-сервиса после входа требует проверки.
5. Нет опубликованного релиза, обновлений и измеренного сравнения производительности.
6. Устаревшие строки в старом README и настройках не следует считать описанием актуального поведения; список расхождений есть в WORK_LOG.
