# myBro: прежняя WebKit-версия

## Сборка прототипа SwiftUI

Прототип на WebKit требует macOS 14 или новее. Восстановленные вкладки создают веб-представление при первом выборе.

Откройте `myBro.app` из Finder. Для сборки из исходников выполните `sh build.sh` в этой папке на Mac с Xcode или соответствующими Command Line Tools. Сценарий собирает приложение для архитектуры текущего Mac и подписывает его локальной подписью ad hoc. Нотаризация для публичной раздачи не выполнена.

## Вкладки и группы

Слева в горизонтальном ряду находятся названия групп со счётчиками и меню «Все группы». Клик по названию показывает вкладки этой группы и возвращает к последней выбранной странице. Для перехода к остальным вкладкам выберите «Вкладки без группы» в меню со стрелкой. «+» и `⌘T` создают вкладку в текущем наборе. Новая группа создаётся через «Все группы». Правый клик по вкладке открывает действия закрепления и переноса, а правый клик по именованной группе открывает переименование, выбор цвета и удаление. При удалении группы её страницы переходят к вкладкам вне групп. Идентификатор прототипа сохранён для данных версии 0.1.

## Пароли и перенос профиля

В меню браузера или в настройках откройте «Пароли». myBro предлагает сохранить пароль после отправки подходящей формы. Сохранённые записи привязаны к точному HTTPS-адресу сайта, включая нестандартный порт. При нескольких логинах введите имя пользователя, чтобы выбрать нужную запись. В инкогнито менеджер недоступен.

В разделе «Перенос профиля» выберите Vivaldi или Яндекс Браузер. В мастере можно объединить три источника данных.

1. Папка профиля (например, `Default` или `Profile 1`) содержит закладки, локальную историю, загрузки и сохранённые сессии поддерживаемого формата.
2. Для вкладок, открытых сейчас, загрузите распакованное расширение из `Tools/TabExport` в исходном браузере. Нажмите его значок, сохраните `mybro-tabs.json` и выберите его в мастере. Альтернативный источник — читаемый файл сохранённой сессии. Выбранный файл вкладок имеет приоритет над сессией из папки профиля. Стандартные группы и рабочие пространства Vivaldi из подходящего файла сессии сохраняются с названием исходного браузера.
3. Для паролей выберите CSV, экспортированный штатным менеджером исходного браузера. Записи для HTTP и HTTPS сохраняются в Связке ключей, включая записи без логина. Автозаполнение работает на HTTPS. Автозаполнение можно включить в мастере. CSV содержит открытые пароли, поэтому выбирайте его в myBro локально.

Нажмите «Проверить данные» для просмотра количества записей и пропусков, затем «Импортировать». Мастер добавляет данные в текущий профиль. Зашифрованные файлы сессий и группы, которые не видны стандартному API вкладок, cookies, расширения и данные синхронизации остаются в исходном браузере. Для рабочих пространств Vivaldi используйте папку профиля и сохранённую сессию.

Зашифрованный архив `.mybroprofile` переносит закладки, историю, вкладки, группы, поддерживаемые настройки, метаданные загрузок и пароли myBro. Для импорта понадобятся сам архив и парольная фраза. Импорт объединяет данные с текущим профилем. Существующие сохранённые пароли при совпадении сайта и логина сохраняются.

- [Экспорт данных Vivaldi](https://help.vivaldi.com/desktop/tools/import-and-export-browser-data/)
- [Перенос данных Яндекс Браузера](https://browser.yandex.ru/help/ru/personalization/transfer)

## Основания и проверка

Для проверки cookies, прогресса и совпадающих имён файлов запустите `rtk proxy python3 Tests/download-fixture.py`. Передайте выведенный локальный URL тесту из второго терминала.

```sh
rtk proxy mkdir -p .build/modules
rtk proxy swiftc -parse-as-library -module-cache-path .build/modules \
  Sources/Address.swift Sources/BrowserLibrary.swift Sources/Browser.swift Sources/Downloads.swift \
  Sources/PasswordVault.swift Sources/PasswordForms.swift Sources/ProfileArchive.swift \
  Sources/ProfileMerge.swift Sources/ChromiumProfile.swift Sources/ChromiumSession.swift Sources/BrowserPreferences.swift Sources/BrowserMigration.swift \
  Tests/BrowserTests.swift -o .build/webkit-browser-tests
rtk proxy .build/webkit-browser-tests --download-fixture http://127.0.0.1:ПОРТ/
```

Для проверки импорта и архива замените в команде компиляции `Tests/BrowserTests.swift` на `Tests/ProfileTests.swift` и запустите получившийся бинарник без URL. Флаг `--webkit` дополнительно проверяет автозаполнение с временной записью в Связке ключей.

Для изучения проверил [Craft Anything 0.6.1](https://github.com/storytold/craft-anything/releases/tag/v0.6.1) и запустил его CLI в режиме Clean Room с изолированным профилем для захвата окна Яндекс Браузера. macOS отказала в захвате до запуска браузера. Сценарии сверены по публичной справке. Сборка не включает код и ресурсы Craft Anything или Яндекс Браузера. [Вкладки](https://browser.yandex.ru/help/ru/search-and-browse/tabs-actions), [группы](https://browser.yandex.ru/help/ru/search-and-browse/groupoftabs.html), [боковая панель](https://browser.yandex.ru/help/ru/personalization/sidebar), [расширения](https://browser.yandex.ru/help/ru/personalization/extension), [сертификаты](https://browser.yandex.ru/c/pay_cert).

Быстродействие и расход памяти в сравнении с Яндекс Браузером не измерены. Размер сборки отражает только приложение. WebKit и его процессы предоставляет macOS.

Для полного паритета с настольным браузером отдельной проверки требуют расширения и совместимость сайтов. Если обязательна поддержка API расширений Chromium, системный WebKit не даёт её из коробки. На базе Chromium можно сохранить совместимость этого уровня ценой поставки и регулярного обновления отдельного движка.
