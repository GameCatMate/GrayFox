# myBro: настройки, данные и управление

Новая версия использует независимый профиль Firefox и нативные предпочтения; [карта и настройки Gecko-версии](../Firefox/README.md). Ниже перечислены ключи сохранённого WebKit myBro.

Снимок 19.11.2026. Значения ниже — исходные defaults кода, а не прочитанные персональные настройки пользователя.

## Разделы интерфейса

| Раздел | Доступные группы |
| --- | --- |
| Общие настройки | Профиль и импорт, поиск. |
| Интерфейс | Тема, стартовая страница, вкладки и группы, панель закладок. |
| Инструменты | Пароли, загрузки, снимки, PDF, переход в менеджер расширений. |
| Сайты | Запросы камеры/микрофона, масштаб. |
| Системные | HTTPS по умолчанию, очистка истории/cookies, сброс настроек. |
| Специальные возможности | Уменьшение движения, минимальный шрифт сайтов. |

Поиск фильтрует группы по названию и ключевым словам. «Безопасность» в верхней навигации ведёт к системному разделу, отдельной страницы аудита безопасности нет. В инкогнито часть групп скрыта, однако настройки `@AppStorage` в основном общие для приложения.

## Непостоянное состояние и фиксированные параметры

- Масштаб отдельной вкладки: `Tab.pageZoomOverride`; не часть `SavedTab`, после полного перезапуска не восстанавливается.
- Скрытие завершённых загрузок, поиски/фильтры внутренних страниц, открытые панели и hover-состояния — UI-состояние, не отдельные профильные настройки.
- Полоса вкладок 36 точек по высоте. Кнопка прокрутки с подложкой тоже 36; значок расположен по центру.
- Вкладка 24–158 точек, промежуток 3; favicon 16×16. Отдельной настройки ширины вкладки нет.
- Заголовок появляется при ширине от 62 точек. На минимальной вкладке крестик по центру; на остальных справа. Круг hover — 16×16.
- Стрелки прокрутки — overlay, не отнимают ширину; fade 0,20 с. При уменьшении движения fade отключён.
- Восстановление вкладки — fade и смещение 4 точки за 0,18 с, если движение разрешено.
- Адресная строка и её кнопки: высота 34, символы 18; радиус адресного поля 10.
- Локальные подсказки начинаются от двух символов; сетевой запрос — 2–160 символов с дополнительными фильтрами и задержкой 220 мс.
- Favicon: ответ не более 512 КиБ, изображение декодируется до 32 пикселей, кеш до 256 записей / 1 МиБ; cooldown ошибки 10 секунд.
- Стек закрытых вкладок ограничен 25 записями. В панели последних загрузок показывается до 9 элементов.

## Где хранятся данные

| Данные | Хранилище |
| --- | --- |
| Постоянная сессия, история, закладки, настройки | UserDefaults домена `org.openstvor.browser`; типичный файл `~/Library/Preferences/org.openstvor.browser.plist`. Изменять вручную при работающем приложении не рекомендуется из-за кеша preferences. |
| Пароли | macOS Keychain: generic-password item, service `org.openstvor.browser.passwords`, account `local-profile`. JSON массива записей внутри Keychain, не в обычном browser-state. |
| Cookies и данные сайтов | Системное `WKWebsiteDataStore.default()`, путь управляется WebKit. В архив myBro не включаются. |
| Инкогнито | Общий для открытых приватных окон непостоянный `WKWebsiteDataStore`; освобождается после закрытия последнего приватного окна. |
| Файлы загрузок | Системная Downloads либо выбранная папка; файлы сохраняются также при инкогнито. |
| Отдельный Chromium | `.build/mybro-chromium-profile`; не общее хранилище с основной оболочкой. |
| Экспорт myBro | Выбранный пользователем `.mybroprofile`, зашифрованный AES-GCM. |

Доверие сертификатам наследуется от macOS. Приложение не добавляет корневой сертификат Минцифры и не удаляет сертификаты из системной Связки ключей.

## Что попадает в экспорт myBro

`Browser.exportProfile` собирает `BrowserData`, пароли, метаданные загрузок и разрешённые настройки:

- оба поисковика, флаги поиска/подсказок и `password-autofill`;
- booleanKeys из `BrowserPreference`;
- тему, режим панели закладок, масштаб по умолчанию, минимальный шрифт;
- локальные заметки.

Не экспортируются `tab-groups-width`, путь `downloads-folder`, индивидуальный pageZoomOverride, веб-хранилища, сами загруженные файлы и локальные данные Chromium. Boolean «спрашивать папку» экспортируется, сам путь папки — нет.

Архив имеет заголовок `MYBROPF1`, соль 16 байт, AES-GCM и PBKDF2-HMAC-SHA256 на 600000 итераций с ключом 32 байта. Парольная фраза — от 12 символов, файл — до 128 МиБ. Это описание формата кода, не независимый криптографический аудит.

## Очистка и сброс

Периоды: час, 24 часа, неделя, месяц, 3 месяца, год, всё время. История посещений и стек закрытых вкладок очищаются по своим датам; при «всё время» очищаются полностью. Отдельные посещения можно удалить по ID.

Cookies удаляются через WebKit `modifiedSince`. Это не команда очистки всех типов данных сайтов.

Сброс настроек удаляет перечисленные в `Browser.resetSettings` keys и возвращает настройки по умолчанию. Закладки, история и пароли сохраняются; заметки и `tab-groups-width` сброс также не удаляет. В инкогнито сброс постоянного профиля недоступен.

## Сочетания клавиш

| Клавиши | Действие |
| --- | --- |
| Command+T | Новая вкладка в текущей группе. |
| Command+W | Закрыть текущую вкладку. |
| Command+Shift+T | Восстановить последнюю закрытую. |
| Command+Shift+N | Новое окно инкогнито. |
| Command+Option+G | Создать группу через меню групп. |
| Control+Tab / Control+Shift+Tab | Следующая / предыдущая вкладка текущей группы. |
| Command+L | Фокус адреса. |
| Command+R | Обновить страницу. |
| Command+[ / Command+] | Назад / вперёд. |
| Command+Y | История. |
| Command+, | Настройки. |
| Command+D | Добавить текущую страницу в закладки. |
| Command+F | Поиск на странице. |
| Escape | Закрыть панель поиска, когда она доступна. |
| Command++ / Command+= / Command+- | Масштаб +10 / −10 процентных пунктов; поддержан вариант с Shift для плюса. |
| Command+0 | Вернуть масштаб по умолчанию, он не обязательно равен 100%. |
| Command+P | Печать страницы. |

## Chromium и инструменты

| Параметр | Значение |
| --- | --- |
| Версия в `Chromium/prepare.sh` | `157.0.8103.78-1.1`. |
| `MYBRO_CHROMIUM_APP` | Необязательный путь к отдельному Chromium.app для launch-скрипта. |
| Профиль по умолчанию | `.build/mybro-chromium-profile`. |
| `--enable-features` | `TabGroupsFocusing,NonGroupFocus`. |
| `--disable-features` | `VerticalTabs,TabGroupRibbon`. |
| `MYBRO_PLAYWRIGHT` | Путь к уже установленному модулю Playwright для JS-тестов; общий модуль `/path/to/playwright/node_modules/playwright`. |
| `--mybro-import` | Специальный запуск с тремя аргументами: имя источника из enum, абсолютная папка профиля и абсолютный путь CSV. При запуске выполняет настоящий импорт; это не dry-run. |

Скрипты сборки Chromium скачивают/собирают исходники при явном запуске; при составлении карты они не запускались.
