## Найденные расхождения документации и интерфейса

1. `BrowserSettingsPage.swift`, раздел вкладок, всё ещё показывает «Минимальная ширина вкладки — 50 точек». Фактическая константа — 24. В этом запросе строка не исправлялась: задача — составить карту.
2. Старый README говорит об управлении только именованными группами и не отражает все поздние изменения вкладок, меню и анимаций.
3. Старый README перечисляет только начальные возможности адреса; сетевые подсказки и выбор поисковика расширены в текущем коде.
4. Старый README описывает сохранение только в системную Downloads, хотя уже есть настройка папки и опциональный запрос.
5. Название «превьюшка вкладки» в обсуждении означало favicon. Полноценные hover-скриншоты вкладок не реализованы.
6. Пункт «Расширения» существует в основном интерфейсе, но открывает отдельный Chromium; расширения не внедрены в WebKit-вкладки.
7. «Полный импорт» в обсуждении — целевой сценарий. Реализован перенос поддерживаемых категорий с явными пропусками, без cookies/веб-хранилищ/расширений и не всех зашифрованных сессий.
8. В панели закладок опция значков использует общий globe; favicon загрузчик не подключён к её элементам.
9. Имена Stvor в исходнике, bundle ID, Keychain service и LICENSE оставлены от начальной основы. Название UI — myBro. Простое переименование идентификаторов может отделить существующий профиль и Keychain от приложения.

## Переход на Gecko — 19.11.2026

По прямому запросу пользователя создан отдельный myBro Firefox на закреплённом Firefox 160.0.1. WebKit-бинарник и исходники сохранены; SHA-256 прежнего бинарника: `8890b8d2531f4cb639005885e68f9f22073b79fde20fae3d9210712d0344d7e0`.

Проверены подпись и SHA-256 официального DMG. Открытый интерфейс встроен в отдельное приложение со своим bundle ID и профилями. Проверены настоящие вкладки/группы, восстановление, перенос мышью, внутренние страницы, закладки, история, автозаполнение HTTPS-формы и загрузка без запроса. Временный MV2 блокирует реальный запрос к локальному серверу; официальный подписанный uBlock Origin 1.76.4 устанавливается и активен. Проверена аутентифицированная AES-GCM упаковка, отбрасывание изменённого архива и восстановление данных после перезапуска. Визуальный снимок настроек проверен глобальным Playwright: шесть разделов, без горизонтального переполнения, без непомеченных полей.

При переносе реального профиля обнаружены ограничения Gecko для адресов истории; добавлено локальное совместимое хранение неподдерживаемых адресов и записей без даты. Полный повтор в частично заполненную папку был отклонён автоматической проверкой из-за риска дубликатов; создан новый пустой целевой профиль. Исправление дополнительных записей выполняется отдельно, без повторной вставки нативных посещений.

Перенесены 215 вкладок, 4 группы, 111 закладок и 2 записи загрузок. В источнике 48266 строк истории; каждая запись сверена: 47832 в Places и 434 в дополнительном файле, отсутствующих нет. Gecko отклоняет часть длинных адресов уже на уровне canAddURI, поэтому они сохраняются в дополнительном файле без обрезки. При проверке в новой сессии 213 вкладок остаются отложенными, их страницы не загружены одновременно.

Реальные пароли не выведены и не экспортированы в промежуточный файл. Штатное чтение прежнего Keychain возвращает `-25320: In dark wake, no UI possible`; требуется активный разблокированный сеанс macOS. Для последующего добавления паролей предусмотрен `migrate.py --passwords-only` с явным путём нового профиля. В старой версии парольное хранилище не изменено.

Публичный релиз, подпись Developer ID/notarization и измерения памяти/скорости не выполнялись. Инструменты crapper/dryer/mutator отсутствуют. Подробная архитектура, ограничения и воспроизводимые команды: `Firefox/README.md`, `Firefox/THIRD_PARTY.md`.

Заключительные проверки обнаружили и устранили сброс выбранной вкладки при восстановлении группы: события нативного выбора теперь принимают выбранную вкладку, а не повторно выбирают первый элемент группы. Подтверждено восстановление активной внутренней страницы после перезапуска. Прежний массив закрытых вкладок имел обратный порядок; восстановление теперь выбирает запись по наиболее позднему времени закрытия. В приватное окно добавлена постоянная метка «Инкогнито». Все 10 проверок переноса/перезапуска прошли. Свежий сервис профилей подтверждает новый полный профиль как default. Проверка реального fullscreen ограничена состоянием dark wake: ОС не переключила окно; требуется визуальная проверка в активном сеансе.

Финал: прошли 2 сборочные, 21 runtime, 8 native и 10 migration проверок. Подпись нового приложения проверена codesign --verify --deep --strict. Обычный запуск через LaunchServices подтвердил открытие places.sqlite полного профиля Imported-2026-11-19; приложение оставлено открытым. Удалены 31 промежуточная собственная сборка и 64 одноразовых тестовых профиля, сохранены две предыдущие сборки, официальный upstream и архив WebKit. Тестовый HTTP-сервер остановлен, DMG отсоединён. Повторно подтверждён исходный SHA-256 старого бинарника. Graphify обновлён и перекластеризован: 1248 узлов, 2860 связей, 122 сообщества; внешний LLM не использован. Перенос настоящих паролей остаётся ожидающим разблокировки macOS.

## Пустое место после закрытия вкладки — 19.11.2026

Воспроизведено нажатием крестика: tab.closing=true и fadein снят, но невидимая вкладка продолжает занимать 158 px, соседняя остаётся справа.
